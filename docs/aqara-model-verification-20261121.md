## 本轮确认

- 两卫暖风/换气/干燥一体机选奥普米家版。用户记得“带干燥、排气、温度的那款”，没有完整型号；这些功能描述不足以唯一识别产品，不编造SKU。
- 门锁必须带可视猫眼。独立可视门铃取消，Excel编号04数量为0；原客餐厅E1不变。
- 电竞灯带优先较新的T2；主卧增加S1 Plus桌面版候选；H1无线旋钮保留原方形需求，V1桌面版另作互斥升级。
- 电竞房选FP310后，独立温湿度计先不买（编号18数量0）。两卫原有FP310继续复用。
- 次卧照明不加，窗户仅检测；空调/新风/地暖/热水器仍为欧瑞博。奥普米家版是本轮明确的品牌范围例外，不扩大其他小米/米家或华为设备采购范围。

本轮实际读取了[Aqara中国大陆当前产品目录](https://www.aqara.cn/prodCenter)、下表产品页及可用规格/支持正文，并提取官网指向的商品链接。**官网有产品页不等于实时有货，也不等于该产品是新一代。** 京东购买入口在浏览器跳到登录页，未获得当前地区库存、成交价或可下单结果；线下产品需折扣渠道确认。表中销售状态因此没有标为“现货已确认”。

官网仍列出的T1传感器可作为渠道询价候选，不能仅凭T1后缀判定过时。猫眼锁需另对待：本轮查到星耀和H100，但均为较早产品，未验证到更新的大陆版Aqara猫眼锁。**门锁暂不定型，不用旧款冒充新款，也不以D200的人脸摄像头替代可视猫眼需求。** 若渠道无法提供当前新品与明确售后，应保留空缺再比较，不默默增加独立门铃。

## 奥普米家版怎样与绿米联动

拟采用：**两卫FP310 → Aqara网关 → Home Assistant → Xiaomi Home集成 → 奥普米家版一体机**。这是一条待具体机型验证的联动路线，尚未部署或验收。

“加入米家”不表示能直接配对Aqara Home，也不表示M200可以桥接任意米家设备。小米官方维护的[ha_xiaomi_home项目](https://github.com/XiaoMi/ha_xiaomi_home)及[中文说明](https://github.com/XiaoMi/ha_xiaomi_home/blob/main/doc/README_zh.md)提供HA接入：当前说明支持大多数米家设备，但排除蓝牙、红外和虚拟设备；并非有米家标识就必然完整支持。没有适用小米中枢时，通常通过小米云控制；不承诺全离线，也不预先增加小米网关。

选定SKU后先验证四项：

1. 米家账号/地区下可添加，实际连接协议受到所选集成支持。
2. HA可分别读写换气、干燥、暖风、正常停止；确认温度是实测值还是设定值，核运行状态反馈，不能凭用户记忆推定实体齐全。
3. FP310湿度能经选定Aqara路径进入HA，更新节奏足以做排湿。官方[FP310支持页](https://www.aqara.cn/presence_multi_sensor_FP310_support)已确认温湿度检测，但跨平台实体仍待实机核验。
4. 手动面板、定时程序、温控/过热保护和停止后散热保留；断网或数据陈旧时不误触发。湿度联动先做换气，干燥/暖房优先明确主动触发。

两卫接入配件数量保持空白，型号待定；软件集成可用时可能无需额外硬件。不先买绿米继电器、红外盒或智能插座来给整机切电。

## 会影响购买的兼容性

- **磁吸系统**：旧PDF为20磁吸/48V，V1官方轨道宽26.6mm。V1可做完整新系统候选，若轨道已施工则先按实物找匹配灯具；同品牌、同电压也不保证接触结构兼容。保持原签字灯带及其驱动不变。
- **家电计量**：T1插接款2500W，H2墙插明确10A/最大2500W；都不是通用16A家电方案。先核铭牌、插头和安装空间，再核HA实时功率W实体。计量可推断运行/疑似完成，不能读取洗涤程序、剩余时间或故障码。机器保持正常供电，不按低功率自动断电。
- **屏与旋钮**：S1 Plus桌面版及V1桌面旋钮均需USB-C 5V2A；H1无线版用电池。Aqara屏不作为通用HA网页屏。产品支持Apple Home不保证每个旋钮动作、功率、区域或视频都可导出。
- **门锁**：星耀/H100的HomeKit描述主要是锁控；猫眼画面、录像、通知、家庭钥匙均需分别确认。先验门体及所需猫眼体验，再确认生产日期、国行售后与渠道新货。
- **安全检测**：天然气报警器针对甲烷，不适配所有气种；烟感数量需按实际覆盖。阀门T1仅为后置止水候选，不默认包含管路改造或适配燃气阀。

本轮只更新采购建议、Excel和记录，没有联系商家、下单、改接线或配置自动化。最终渠道报价仍需完整SKU、地区版本、实际库存/交期、生产日期、保修、安装配件及费用。
