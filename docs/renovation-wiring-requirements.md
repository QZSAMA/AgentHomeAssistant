### 2.2 当前 AP 与终端接入约束

两台EAP775-Wall三频面板、1台EAP772三频吊顶；上联2.5G。775下联为1×2.5G+3×1G，主卧终端可使用；工作室Mac/NAS/J3455/PC直连交换机，Apple TV/投影可接AP的1G下联。无线覆盖与次卧可用性装修后实测；既有TL-7DR3630临时补盲时为有线AP模式、独立管理与市电。

### 2.3 交换机、服务器与端口预算

中央ES206五铜口预分配给Fusion和四主干；次卧未接设备时实际空闲一口。ES206为4口PoE++、120W总，ES210为8口PoE++、200W总；单口均最高90W。775标称45W含25W转供，当前禁用转供；772最大25.4W。工作簿按at端口30W分配作初步核算，到货按at/bt协商与控制器预留复核，不用差值推裸机功耗。

电竞房只有一台ES210XPP-M2，两10G口分别给Mac和未来NAS；其8个2.5G口完整直连影音设备时可占满。Apple TV/投影改接775的两个1G口后可释放两口。NAS与J3455均在箱外通风位置，NAS及其SFP+介质入住后再选；不将DAC埋墙，不买NAS网卡。

### 2.4 房间多设备扩展

主卧有线终端接Wall AP下联；次卧当前只有一个中央RJ45预留口，若同时启用旧路由器和电脑，使用旧路由器实际可用的下联口。电竞房/大厅由本地交换机扩展，不追加第二条主干。所有跨房流量共享各房2.5G上联；同交换机同VLAN的Mac/NAS与影音流量本地交换。

### 3.2 中央通信柜与房间小弱电箱

不得再以旧的“400×300×100 mm”或“8/16 口千兆”作为自动结论。施工前应拿最终 BOM 实物尺寸复核：

- 中央位置的光猫、Fusion主路由（含内置控制器）、中央交换机、配线模块、电源与 UPS；工作室位置的交换机、Mac/J3455/未来 NAS、后备电源，以及存储设备的占位、重量与硬盘维护空间分别核算；
- 插头厚度、网线弯曲半径、维护操作面、散热和防尘；
- 设备总功耗、通风路径、接地和独立电源插座；
- 门板关闭后是否会压线、阻碍散热或影响无线设备。

仅电竞房/大厅两处小箱按各自交换机/适配器/配线复尺，可开门维护、本地供电/通风；AP/无线网关在箱外。主卧/次卧不设设备箱；主卧核面板AP底盒/下联，次卧核RJ45墙口与未来AP安装空间。工作室ES210XPP-M2及SFP+/DAC插头、弯曲空间与散热单独核对，不再以卧室小箱套尺寸。

工作室按单台 ES210XPP-M2 实物核型；旧 TL-SX1008/SX3206HPP 的尺寸不能再作为已选设备施工依据。静音由用户另行考虑；箱内仍需电源线、插头、Cat6A/DAC 弯曲与检修空间，实物工作温度与管理能力需验收，不添加第二台交换机补口，不增加工作室 AP 独立注入器。

### 3.3 供电与 UPS

- 安装地已确认中国大陆；中央柜和房间小箱按最终设备数量预留符合当地市电、电气规范及适配器铭牌的插座和接地。美国采购型号需核对输入电压范围、插头与当地供电兼容性，不能仅凭美国销售渠道假定可直接使用。
- UPS入住后再评估增添，不列入住前必购或强制验收。装修先为中央柜、电竞房/大厅交换机、Mac/J3455及未来NAS留插座、承重和通风位置；原至少1小时仅为后续评估目标。
- 主卧AP由中央PoE供电，次卧当前只留RJ45且默认关闭PoE，不采购卧室网络箱UPS；AP下联电脑等市电终端不随PoE保活。后续中央UPS不覆盖电竞房/大厅本地设备，需分散UPS或合规后备回路。容量据实测W/VA/峰值/电池曲线核算，PoE负载不在交换机整机输入中重复相加。
- Mac、J3455与未来高速NAS均规划在工作室箱外。入住后若加UPS，工作室后备供电计这些主机、ES210XPP-M2及其AP和必要排风，不计入中央负载。届时测试约定负载下续航，并验证低电量先保存/停服务、再安全关机；当前仅做供电与维护空间预留。

### 3.4 大厅—电竞房影音线路

- 大厅与电竞房之间按用户确认各预留 **1条约10m主动光纤 HDMI AOC**，方向独立：大厅影音源区 `HDMI OUT` → 电竞房投影端 `HDMI IN`；电竞房影音源区 `HDMI OUT` → 大厅电视 `HDMI IN`。两条不是一根可反向使用的线，也不是网络主干，不计入Cat6A数量。
- 两线各自进可抽换管路/可检修路径，避免墙内永久耦合器。施工方先核实际线路长度、线头尺寸能否穿管、弯曲半径/牵引限制、强弱电分隔、接口端留量及有源线是否需要 USB 辅助供电。准确长度待现场复尺，不按约10m直接下料。
- AOC 方向端头须按线身 `Source`/`Display` 或 `TX`/`RX` 标识安装；线缆不能剪接、压扁、钉固或小半径盘绕。封板前先用实际源和显示设备逐条测试需要的分辨率/刷新率、HDR、HDCP、CEC/VRR等功能，并拍照记录两端标签及路径。
- 电竞房投影墙尚未定；先以可调整候选设备区描述，不指定最终吊装点。依据具体投影型号/投射比、投射距离和幕布/墙面复尺后，确定投影输入端、插座和支架位置。施工明细与游戏/串流方案见[影音与游戏连接规划](av-and-gaming-layout.md)。
