# 弱电布线与智能家居施工需求

> **用途**：供户型复核、装修水电施工和设备采购前的共同基线使用。本文只记录目前已确认的户型事实和施工硬约束；未确认项不得直接交底为已定方案。
>
> **更新时间**：2026-10
>
> **关联记录**：[家庭基础设施登记与实施台账](home-infrastructure-register.md)、[设备选型清单](device-selection-list.md)

## 0. 当前结论（施工前先看）

1. 全屋为一层矩形住宅。已知房间和卫生间见第 1 节；大厅/公共区域的边界和尺寸仍待现场复尺。
2. 网络基线为：**入户光纤 → 光猫/ONT → 主路由器/网关 → 管理型多千兆 PoE 交换机 → 四个有线回程 AP**。
3. 四个 AP 点位为主卧、次卧、工作室/电竞房、大厅。每个 AP 必须是 Wi‑Fi 7 墙面/入墙型设备，并同时具备：上联至少 2.5GbE、另一个给电脑等终端使用的有线端口至少 2.5GbE。
4. 单口吸顶 AP、只有一个 2.5GbE 口的 AP，或用独立墙插/房间小交换机替代 AP 自带端口，均不满足本项目要求。
5. 光猫桥接、网关型号、AP 具体型号、交换机最终端口数和机柜尺寸尚未锁定；必须按最终设备 BOM 和现场测量复核。

## 1. 户型与点位基线

### 1.1 已确认的平面关系

方向按“上=户型图上方、下=户型图下方”记录：

| 区域 | 相对位置 | 已知关系/用途 |
|------|----------|---------------|
| 主卧 | 左上角 | 主要卧室；Bathroom A 的门朝向主卧 |
| 次卧 | 右上角 | 第二间卧室 |
| Bathroom A | 主卧与次卧之间 | 两个卧室之间的卫生间，门朝主卧 |
| 工作室/电竞房 | 左下角 | 工作、开发、电竞等功能性房间 |
| Bathroom B | 工作室右侧 | 门朝上；作为全屋公共卫生间 |
| 入户门 | 右下角 | 住宅入口 |
| 大厅/公共区域 | 房间之间的公共区域 | 存在但边界、面积、墙体和家具位置待现场复尺 |

厨房、阳台、客厅、书房等名称目前**不是已确认的施工事实**。如现场确有对应区域，应在复尺图上重新命名、编号后再增加点位。

### 1.2 AP 点位编号

| 编号 | 覆盖区域 | 建议安装原则 | 当前状态 |
|------|----------|--------------|----------|
| `AP-MASTER` | 主卧 | 墙面/入墙安装，避开金属柜和床头遮挡；保留 AP 本地电脑端口可达性 | 施工预留 |
| `AP-SECOND` | 次卧 | 墙面/入墙安装，靠近房间中心或主要使用墙面 | 施工预留 |
| `AP-STUDIO` | 工作室/电竞房 | 墙面/入墙安装，靠近电脑和 Mac Studio 使用区但不封闭在柜内 | 施工预留 |
| `AP-HALL` | 大厅/公共区域 | 墙面/入墙安装；最终墙面由现场家具和热力图确认 | 施工预留 |

四个点位先按 Cat6A 预埋；最终是否全部上电运行，应在家具布置和实测热力图完成后确认，不能因此减少预埋点。

## 2. 网络拓扑与设备角色

### 2.1 拓扑

```text
入户光纤
   │
光猫/ONT（桥接优先，具体由运营商确认）
   │ WAN
主路由器/网关（NAT、防火墙、DHCP、VLAN）
   │ LAN 多千兆上联
管理型多千兆 PoE 交换机（弱电箱或通信柜）
   ├── AP-MASTER（有线回程）
   ├── AP-SECOND（有线回程）
   ├── AP-STUDIO（有线回程）
   └── AP-HALL（有线回程）
```

“AC”需先澄清含义：若指无线控制器（Access Controller），它不是光猫和交换机之间的主网关，应作为 LAN 内的控制器接入；只有承担 WAN、NAT 和防火墙功能的设备才放在光猫之后作为主路由/网关。

### 2.2 AP 的不可变硬约束

| 要求 | 验收口径 |
|------|----------|
| 形态 | Wi‑Fi 7 墙面/入墙型 AP；具体型号须以厂商官方规格书复核 |
| 上联 | AP 的 PoE/网络上联端口标称至少 2.5GbE |
| 本地终端口 | AP 还必须提供一个独立的有线客户端端口，标称至少 2.5GbE，用于该房间电脑等设备 |
| 回程 | 四个 AP 均使用交换机到 AP 的有线回程，不以无线 Mesh 作为主方案 |
| 替代方案 | 独立墙面网口或只有一个端口的 AP 不能替代“AP 自带额外端口”；房间小交换机只能作为多设备扩展，不能用来补足 AP 的硬性端口要求 |
| 供电 | AP 由交换机 PoE 供电；最终 PoE 标准按选定型号确认（不得凭旧型号假设） |

因此，当前不能把任何“单个 2.5GbE 上联口”的吸顶 AP 当作满足项。UniFi、Omada 或其他品牌只能在同时满足上述两个 2.5GbE 端口条件、并完成北美版本/固件/PoE 规格核验后进入候选 BOM；目前不视为已定型号。

### 2.3 交换机、服务器与端口预算

- 交换机必须是可管理的多千兆 PoE 交换机。按当前已知角色，端口基线至少为 **8 个多千兆 RJ45/PoE 端口**（4 个 AP + 网关/上联 + Mac Studio/服务器 + 控制器或其他设备 + 备用）；若最终服务器、控制器或其他终端占用更多端口，应按 BOM 增加，不能把“8 口”当成无条件上限。
- 端口速率至少覆盖 AP 的 2.5GbE 需求；网关到交换机以及 Mac Studio/服务器的上联优先预留 10GbE 能力。
- PoE 预算按最终设备铭牌最大功耗计算：`PoE 总预算 ≥ 四个 AP 最大功耗之和 × 1.3 + 其他 PoE 设备最大功耗`。不得继续使用旧清单中的固定功耗或固定瓦数假设。
- Mac Studio、Home Assistant 主机、模型/视频工作数据和备份设备放在工作室或独立设备柜，不放入密闭弱电箱；至少预留 2.5GbE，若硬件支持则预留 10GbE。

### 2.4 房间多设备扩展

AP 的额外 2.5GbE 端口优先直接连接房间电脑。若一个房间需要连接多台电脑、电视或其他有线设备，可在 AP 端口后增加**非密闭、无风扇（fanless）的 2.5GbE 小交换机**，并按设备数量和上联带宽核算；小交换机应放在可维护、通风的位置，不能塞进墙体、踢脚线或密闭柜内，也不能反过来作为 AP 缺少额外 2.5GbE 端口的补救方案。

## 3. 结构化布线要求

### 3.1 主干与材料

| 项目 | 当前要求 |
|------|----------|
| 永久链路 | Cat6A 实芯纯铜（禁止 CCA/铜包铝），两端按 `AP-*` 编号 |
| 拓扑 | 弱电箱/通信柜为星型汇聚点；不串接、不在墙内放不可维护的耦合器 |
| AP 线缆 | 每个 AP 至少 1 条独立 Cat6A；条件允许时另敷备用管/备用线，便于更换和升级 |
| 服务器点位 | 工作室或设备柜至少 1 个 2.5GbE，优先 10GbE；具体位置待家具和 Mac Studio 尺寸确认 |
| 线管 | 弱电、强电分管；交叉尽量垂直，平行敷设按当地规范保持间距；预留牵引线和弯曲余量 |
| 标识 | 施工图、线缆两端、配线架/交换机端口使用同一编号；保留竣工照片和测试记录 |

### 3.2 弱电箱/通信柜

不得再以旧的“400×300×100 mm”或“8/16 口千兆”作为自动结论。施工前应拿最终 BOM 实物尺寸复核：

- 光猫、主路由/网关、PoE 交换机、控制器、配线模块、电源适配器和 UPS 的占位；
- 插头厚度、网线弯曲半径、维护操作面、散热和防尘；
- 设备总功耗、通风路径、接地和独立电源插座；
- 门板关闭后是否会压线、阻碍散热或影响无线设备。

如果测量后紧凑型 8 口多千兆 PoE 设备能够满足最终 BOM，可以继续使用；若不满足，再改用更大的通风通信柜或把交换机移到附近设备柜。不能在未测量前断言必须更换，也不能把不合尺寸的设备硬塞入弱电箱。

### 3.3 供电与 UPS

- 弱电箱/通信柜按最终设备数量预留足够的 220V 插座和接地，不少于光猫、网关、交换机、控制器、UPS 适配器所需数量。
- 光猫、主路由、交换机和 Home Assistant/控制器应接 UPS；UPS 容量按这些设备的实测功耗和目标续航计算。
- Mac Studio 的工作区另设可靠电源和散热，不与密闭弱电箱共用不便维护的插排。

## 4. 电气与智能设备施工要求

### 4.1 开关底盒与零线

智能开关的现行原则是优先零火版，但最终开关数量和回路须按现场照明图确认。已确认的空间均应在每个智能开关底盒预留：火线 L、零线 N、负载回线/控制线和足够的盒深（建议 60 mm，至少按所选设备安装要求）。卫生间等潮湿区域还必须满足当地电气和防水规范。

| 空间 | 当前施工要求 |
|------|--------------|
| 主卧、次卧 | 门口及床边需要的开关回路由照明图确认；预留 N 线和深底盒 |
| 工作室/电竞房 | 按主灯、工作照明和设备区回路确认；电脑/服务器电源与照明回路分开规划 |
| 大厅/公共区域 | 入户和主要通行区的灯光回路现场编号；不预设“客厅”名称 |
| Bathroom A、Bathroom B | 仅按现场灯具、排风/暖风及安全规范布置；智能化设备需确认防潮等级 |
| 入户处 | 玄关/入户灯和网关电源位置现场确认；不把入户门旁等同于固定“客厅”点位 |

### 4.2 当前已知设备的电源准备

| 设备/区域 | 要求 | 状态 |
|-----------|------|------|
| HomePod mini | 主卧、次卧、工作室/电竞房各预留可维护的普通插座；数量仍待确认 | 当前计划 |
| 大厅 Apple Home Hub | 预留普通插座和稳定 Wi‑Fi/有线网络覆盖；具体型号和上市状态未确认 | 待确认 |
| Mac Studio/服务器 | 工作室或设备柜独立电源、散热和 2.5/10GbE；不放密闭弱电箱 | 当前计划 |
| Aqara 网关 | 靠近网络和电源、便于维护的位置；具体型号以设备清单为准 | 待选型 |
| 窗帘、投影、NAS、摄像头等 | 只有在确认会采购及现场位置后再出施工点位 | 未确认，不得当作当前事实 |

## 5. 传感器与自动化预留

绿米（Aqara）是当前主要生态，设备通过 Apple Home 和 Home Assistant 的实际集成能力验收。传感器位置只做可调整的预留，不以旧房间名称锁死：

- 主卧、次卧、工作室/电竞房和大厅：按遮挡、视场和电池维护规划人体存在/温湿度传感器；
- 入户门及现场确认的外门窗：预留门窗传感器位置；
- Bathroom A、Bathroom B：按漏水风险和维护可达性规划水浸传感器；
- 具体型号、数量和是否需要有线电源，待设备清单与家具图确认。

## 6. 施工验收清单

### 水电施工中

- [ ] 已按户型复尺图标出 `AP-MASTER`、`AP-SECOND`、`AP-STUDIO`、`AP-HALL`，并确认墙面/入墙安装面。
- [ ] 四条 AP 链路均为独立 Cat6A 实芯纯铜线，线缆两端编号一致并留有余量。
- [ ] 施工图明确：每个 AP 需同时满足 ≥2.5GbE 上联和 ≥2.5GbE 额外客户端口；未把独立墙插或小交换机计入“满足”。
- [ ] 交换机端口、PoE 标准和预算已按最终 AP 最大功耗之和 × 1.3（再加其他 PoE 负载）复核。
- [ ] 光猫桥接/网关角色已与运营商和网络实施方确认；若使用 AC 控制器，已标注为 LAN 内设备。
- [ ] 弱电箱/通信柜已按最终 BOM 测量插头、弯曲半径、通风、UPS 和维护空间。
- [ ] 所有已确认智能开关底盒均有 N 线，强弱电分管，卫生间符合防水和电气规范。

### 硬装完成后

- [ ] 四条 AP 链路用认证测试仪完成 8 芯、长度和速率测试，并保存报告。
- [ ] 使用最终 AP 样机/规格验证：上联协商速率 ≥2.5GbE，额外客户端口协商速率 ≥2.5GbE。
- [ ] 交换机 PoE 实测能够同时带起四个 AP，并保留预算余量；网关、交换机和控制器可由 UPS 供电。
- [ ] 设备柜/工作室的 Mac Studio 网络、电源和散热可维护，弱电箱门关闭后无压线和过热。
- [ ] 竣工图、端口映射、测试记录和现场照片归档到项目文档。

## 7. 历史资料隔离说明

旧版本中出现的“客厅、书房、厨房、阳台”点位、固定的 400×300×100 mm 弱电箱、8/16 口千兆交换机以及旧的 AP/路由器数量，均为历史草案或未复核假设。它们不构成当前施工承诺；如需沿用，必须在复尺图和最终 BOM 中重新确认。
