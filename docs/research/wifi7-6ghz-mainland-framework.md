# 中国大陆 Wi-Fi 7 / 6GHz 可用性调研框架

研究日期：2026-10-13。主报告：[中国大陆 Wi-Fi 7 / 6GHz 调研报告](../wifi7-6ghz-mainland-china-research.md)。

## 研究范围

面向本项目暂选的 EAP775-Wall（美国版）×3、EAP772 吊顶 AP 候选×1，回答：大陆普通住宅是否获准使用 6GHz、技术上是否有成功连接的公开案例、哪些启用方法有依据且能迁移到本项目。香港、澳门、台湾与海外经验单列，不替代大陆证据。时间范围以截至检索日的现行官方资料为主，历史案例注明日期及版本。

采用 PESTEL 的法律/技术维度分析监管与产品限制，采用 Benchmarking 比较设备和案例条件；不进行市场规模预测，也不凭网友投票估算成功率。

## 证据质量与交付检查

- 官方法规/厂商说明优先；论坛自述不能升级为官方支持。
- Wi-Fi 7 图标、320MHz选项、SSID出现、链路速率，均不能单独证明终端实际连接6GHz。
- 成功记录至少追踪地点、AP SKU/硬件/固件、控制器、终端型号/地区/系统/驱动、实际频率；缺项不补猜。
- 普通家庭合规运行、受控实验及非官方绕过分开讨论。本次仅文献调研，不改变任何设备配置、不声称实机复现。
