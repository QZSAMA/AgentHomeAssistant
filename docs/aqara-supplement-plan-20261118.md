## 起夜灯、卫生间及公共区联动

### 起夜灯

Aqara确有感应小夜灯，官方检索摘要明确自带人体和光线感应、无需无线网络；另找到感应小夜灯插电款的官方说明书入口。适合床侧、床下边缘或走廊低位使用，按插座位置选择插电款或渠道可售的电池款。它提供本地自动亮灭，不作为HA可控灯或可读取的感应器。

如果希望根据睡眠/观影状态调光、统一禁用或定时，改用可联网的低位灯带/灯具并搭配合适触发。主卧原单M1S有夜灯用途，可先看其位置是否能照到行走路径；无需为夜灯另买网关。

### 两卫：FP310与暖风/换气/干燥一体机

FP310具备湿度检测的依据来自Aqara官方产品页的检索收录，官方正文和PDF当前连接失败。原单每卫1只继续使用，不再增湿度计；自动化前验证上报间隔、变化响应和实际HA实体。数据更新节奏会影响排湿启动速度，不能将有湿度传感器等同秒级触发。

用户明确设备是暖风、换气、干燥一体机，非独立排风扇；不能从“松下三干王”或“国产平替”名称推断接线和控制协议。

| 原机可用控制方式 | 建议接法 | 必须明确的条件 |
|---|---|---|
| 厂家支持的智能模块，且有可用Aqara/HA集成 | FP310湿度/存在事件 → Aqara本地规则或HA → 原机换气/干燥/停止命令 | 演示具体SKU、固件、集成和模式控制；只有品牌App可用不等于HA可用。优先这种保留原机逻辑的方式 |
| 真正的红外遥控 | 浴室内可覆盖接收窗的兼容红外控制器模拟原遥控器 | 核实是红外而非433MHz、2.4GHz无线或蓝牙；需要独立的换气、干燥、停止命令。大厅M200不默认能隔墙覆盖浴室；红外路径通常还要解决状态反馈 |
| 厂家明确支持外部干接点/控制输入 | 匹配的绿米继电器或接口模块作用于该控制输入；主机按原要求常供电 | 必须取得该型号接口说明，区分低压/市电、干接点/湿接点、点动/保持及可控模式，由电工或厂家按图安装。不得把市电输出接到低压控制口 |

不通过智能插座或普通墙开关反复切总电源来代替模式控制；一体机可能有加热停止后的散热流程，应按正常停止命令执行。FP310湿度联动首先用于换气；暖风/干燥按用户场景或明确条件启动，不以“有人就加热”作为默认规则。

建议排湿逻辑：湿度相对日常基线持续上升 → 启动换气；回落到较低阈值并持续一段时间 → 延时停止。设置启动/停止不同阈值、最大运行时间和手动优先，参数在入住后按两个卫生间分别校准。

本轮尚未获得候选一体机型号、控制器和接线图，因此给出的是选型与接入路线，不是已核实可用于任意松下/国产机型的接线方案。

### 三干王的实际场景与选型交付

- 主机常供电，保留原厂面板和温控、过热保护、停止后散热等原机逻辑；现有FP310提供湿度/存在信息，自动化通过受支持的接口发送模式命令。
- 自动排湿：每卫分别根据湿度持续上升启动换气，湿度回落并保持后延时发送正常停止命令，设置滞回、最大运行时间及手动优先。
- 洗澡前暖房：保留原厂手动操作；接口验证后可增加主动触发的暖房场景，不做“有人就加热”。
- 洗澡后干燥：优先主动启动主机自带的定时干燥程序，使用习惯明确后再评估自动触发。停止用正常命令，不通过智能插座切电代替。
- 手动切模式后暂缓自动规则，避免自动化立即反向操作；湿度数据过期/离线时不据此触发加热。

向供应商索取：完整主机与控制器型号、接口说明/接线图、换气/干燥/暖风/停止能否分别控制、运行状态反馈、正常停止是否保留散热流程，以及具体HA接入演示。遥控明确红外或射频；有App/无线遥控不等于可接入HA。两卫可用相同路线，但配件数量取决于实际控制距离和接口，不能默认客厅M200隔墙完成。

### FP400、欧瑞博与独立柜灯

- FP400按入户、沙发两个逻辑区域设计。先评估一台的实际视野，墙体/拐角挡住时才考虑第二台；不依赖隔墙定位。进玄关只控制欢迎/通行灯，不凭关门或区域无人判定全家离开；沙发检测可控制局部照明，但不默认坐下就打开电视。具体区域事件能否导出HA须验证，Aqara内能完成的规则可优先在兼容设备间配置。
- 空调、新风、地暖、热水器全部归欧瑞博选型；要求服务商列出四类设备的具体SKU、控制器、可用接口、状态反馈及本地/云端边界。品牌确定不等于四类已经能接入HA/Apple Home；本轮不额外购买绿米空调伴侣或通用供电继电器替代欧瑞博原控制。
- 水吧/餐边柜分别为：普通电源插座 → 智能插座 → 灯具原配电源/驱动 → 灯具。触摸开关灯或断电后默认熄灭的灯具要先验证来电行为；智能插座解决通断，若后续要调光/色温，需另选兼容灯具/驱动，不能靠普通插座调光。

## 家电状态：智能插座增补方案

用户希望了解非智能洗衣机、洗碗机、洗地机等设备的状态。这类需求值得增加计量点，采购目标是**实时功率监测和完成提醒**；插座保持供电，不把自动切断家电电源作为默认方案。每台家电独立计量，不把多台家电接在一个插座后从总功率猜测各自状态。

| 位置 | 建议 | 可以尝试获得的状态 | 限制 |

### 询价与选型条件

1. **功能**：必须有可用于自动化的实时有功功率W；累计电量kWh用于用电统计。只有远程开关或每日耗电报表不够。确认功率上报周期、变化触发方式、低功率分辨能力和离线行为。
2. **接入路径**：不能从“支持HomeKit/Matter”推断功率一定可见。Aqara App能看电量，不等于经M200桥接到HA后也有功率实体；按具体SKU、网关、固件和选定集成方式演示HA读取功率。Apple Home能开关也不代表能直接做功率阈值自动化。若目标路径只暴露通断，则该型号不满足本次HA状态监测目标；只有确认Aqara自身规则足够且用户接受时，才另评估Aqara内完成的提醒路径。
3. **电气与形态**：根据家电铭牌的最大输入、加热/烘干与电机负载、实际10A/16A插头以及厂商允许的负载类型，匹配整条供电链路。不能一律买10A，也不能只把转接插座换16A就认为上游容量够用；不靠转换头适配不匹配的插头。嵌入式洗碗机额外核插接式插座的厚度、可达性及安装说明；如需墙装计量位，应由电工确认，绿米原签字清单数量不变。
4. **适合家电常供电**：确认断电恢复策略可配置且符合机器说明；普通低功率计量不触发插座自动断电，不启用会干扰烘干、保管、充电管理的低功率切断功能。测量家电原有正常工作方式，不承诺断电再上电可远程启动程序。
