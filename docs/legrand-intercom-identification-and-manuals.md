## 1. 当前结论

**2026-11-25续篇**：[新增证据与现场调查方案](legrand-s6819161-investigation-plan.md)补充国内第三方终端对接线索、原厂服务核对单及逐场景验证。官网本轮仍未取得S6819161专用手册或销售型号映射。

**ESP旁路研究补充（2026-11-23）**：[真实项目与本户调查路径](legrand-esp-intercom-bridge-research.md)已核查Doorman、Comelit Simplebus2、按键改造、BTicino视频与ESP32-P4实例。保留原屏接入家庭网络有真实案例，但没有S6819161可直接套用的方案；若本机是标准以太网，优先镜像／TAP只读调查，再决定是否用ESP实现已知协议。

**品牌已确认是 Legrand／罗格朗，背标可读编号为 `S6819161`；尚未取得明确适用于这个编号的完整操作手册，也没有查到它与公开销售型号的可靠对应关系。** 编号可用于后续核对，但不把它未经验证地改写为某个凯乐或凯蕴型号。

已从官网实际下载并核读两份资料，原始PDF及校验记录保存在[资料目录](research/legrand-intercom-20261123/README.md)：

- **凯乐 IP68 产品目录，23页**：681912／681915的尺寸与粗量接近，是继续检索的候选方向；它不是操作手册，也不包含S6819161。
- **凯蕴系列 IU 操作说明书，98页**：确实是完整操作手册，但适用机型列表不含S6819161，尺寸、背面端子和界面示例也有差异。作为排除误配与了解系列功能的参考，**不能照此给本机供电、接线、改配置或刷固件**。

本轮没有确认米家、Home Assistant或Apple Home兼容，没有新增采购或改动门禁。早期研究按HA／Apple Home展开，用户后续明确提到米家；两类目标分别记录，不能把HA可接入等同于米家App能使用。

### 两组红黑线如何影响调查

“独立供电线路加网络通信”是值得先核的假设，但线的颜色和数量不足以确定电路。第二组可能是供电续接，也可能服务于门铃、报警或其他外设；这些只是需要排查的类别，不是对本户接法的判断。

因此目前不把两组红黑线并联、不假定红正黑负，也不选定12V或24V电源。RJ45线另行核实是否通向楼宇对讲网络，不能因为家里有Omada交换机就直接接入或开启PoE。两组电线也不等于存在可接智能继电器的开门触点。

现场识别可按下表记录，工作应由熟悉该系统的安装人员完成；用户不需要为此试接或短接：

| 记录对象（临时标签） | 需要核实的内容 | 状态 |
|---|---|---|
| 红黑线组A | 两端去向、原插头对应的端子编号、上游电源铭牌；需要测量时记录AC/DC、电压和极性 | `not_run` |
| 红黑线组B | 是否与A同一路径，是否另接门铃／报警／外设，实际端子用途 | `not_run` |
| RJ45线路 | 另一端设备和端口、属于楼宇网还是家庭预留网、是否携带供电及其标准 | `not_run` |
| 室内机 | 设置页中的销售型号、固件版本、所属系列、原厂App及本户绑定方式 | `not_run` |

不预先把未知电路归类为低压；确认供电来源和端子定义后，才选择适当的检测方法。

## 4. 已取得的98页完整手册为何不能当成本机手册

来源：[697062官方产品页](https://www.legrand.com.cn/ecatalogue/cn/video-door-phone/1122/697062.html)的“凯蕴系列IU操作说明书”附件。实际使用的[官方附件包下载地址](https://www.legrand.com.cn/ecatalogue/cn/downloads/attachment/download/product_id/11225/?manual=4)返回ZIP，内含`Technical Documents/9734_凯蕴系列IU操作说明书.pdf`，已完整解压保存。

| 核验项 | 手册内容 | 结论 |
|---|---|---|
| 封面／PDF第1页 | `Version_0.2`；2020-02-27；`45-07-R3610100` | 这是特定版本资料，不当作现行通用固件说明 |
| 适用机型／第1页 | 697062、697061、697042、697041、697162、697161、697142、697141 | 不含S6819161 |
| 说明书入口／第80页 | 设置→说明书，可扫码查看对应型号手册；图示为下载App、下载说明书两码 | 与用户纸质简页的入口相似，但图示不是同一版本；不能凭入口认同型 |
| 本机信息／第88页 | 可查看型号、IP、软件及PCBA等版本信息 | 说明核对设备设置页的重要性；本机菜单是否相同仍未确认 |
| 外形／第96页 | 10英寸机型外形280 × 186 mm，具有右侧触键 | 与用户粗量及照片线索不完全匹配 |
| 接线／第97页 | 该系列注明24V、非标准PoE；12V为外设输出，F1–F8为防区 | 证明类似外观和“12V”字样可能被误读；**这些参数不得移植到S6819161** |

手册的第44–46页讨论监视，第80–82页涉及App绑定和呼叫转移。这些功能仅能证明列明系列的文档能力，不证明本户接口、闲时监看、米家或HA接入已可用。

## 5. 原厂联网与第三方接入线索

已阅读的[官方楼宇对讲FAQ](https://www.legrand.com.cn/node/2781)、[Legrand Eliot介绍](https://www.legrand.com.cn/content/legrand-eliot)及[App Store原厂描述](https://apps.apple.com/cn/app/legrand-eliot/id1509844525)显示：兼容产品存在原厂云对讲／云门禁路径。App描述提到明泰、凯蕴，尚无证据将S6819161纳入支持范围；凯乐目录的“扩展手机App”也没有在本次调查中建立到Eliot的确定映射。

网上的Legrand集成不能按品牌一概套用：

- [Legrand Home HA项目](https://github.com/legrand-link/ha_legrand_home)列出灯、窗帘、传感器、暖通、AI屏的开关子功能等；本轮读取版本没有明确列出S6819161、楼宇视频或门禁开锁支持。
- [BTicino Intercom社区集成](https://github.com/k-the-hidden-hero/bticino_intercom)针对进入Netatmo／Home + Security平台的特定海外机型，不能据此推导国内视得安设备兼容。
- 本轮没有找到本机米家官方接入、RTSP、ONVIF、SIP或开门API的确证。没有查到不等于设备必然不支持。

后续顺序仍是：精确型号和原厂手册 → 本户原厂App／联网模块 → 视频、呼叫事件、一次开门的分别验证 → HA／Apple Home／米家各自适配。只有明确硬件电路和接口后，才进一步评估隔离干接点。保留原机，不采购未知适配器。

## 6. 检索记录与剩余缺口

- 2026-11-21：实际下载并核验官方凯乐IP68目录和凯蕴98页手册；另核查明泰22页产品方案册，其型号表没有给出S6819161映射，因此不作为本机说明书归档。
- 精确检索词包括`S6819161`、`6819161`、`681916`、`LE13416AA`及凯乐／IP68／室内智控屏。官方目录一次成功的`681916`查询显示没有结果；其他多次请求超时，不能用网络错误证明资料不存在。
- 2026-11-23：可访问的Bing精确查询未命中；部分泛查询出现无关结果，不采用。官网、部分搜索站出现连接重置；HTTP请求落到当前网络的企业访问限制页。该限制不是厂商撤下手册的证据。未尝试规避网络策略。
- 用户照片中的纸质说明页只有小尺寸菜单示意二维码，本次未解出可用下载链接；不能把它当实际设备生成的说明书地址。
- 已取得的系列手册未建立到`S6819161`的映射，因此“获取本机完整手册”仍未完成。本轮可交付的是资料原件、核验结论与明确缺口。

要进一步确定本机版本，最有区分力的证据是本机设置中的型号／版本，以及实际“说明书”二维码的下载地址；也可由安装商提供对应`S6819161`、`LE13416AA A3`的原厂操作与接线手册。此处列出下一步证据需求，不表示本轮已经取得或向外部发送了请求。
