## 1. 选型与集成原则

- Aqara 设备优先选择能被 Apple Home 和 Home Assistant 稳定发现、控制和更新的型号；不能仅凭“支持 Matter/HomeKit”宣传语视为已验收。
- 智能开关优先零火版；回路、盒深和防潮等级必须与现场电气图及当地规范一致。
- 设备型号、固件、区域版本和购买渠道在下单前锁定，并记录产品页或说明书版本；价格和上市信息随市场变化，不在本文硬编码为承诺。
- 按用户偏好列美国版及 6GHz 候选；地区许可、固件功能和跨境保修未验证，销售规格不等于本户已验收能力。
- 网络分区管理/Omada 是选型方向，工作室/电竞房只设一台 **ES210XPP-M2**；全屋主干按 2.5G，Mac Studio 与高速 NAS 在本地交换机使用两个 10G 口。原两台交换机组合不恢复采购；完整直连表占满十口；Apple TV/投影改接工作室AP数据下联后可释放两个2.5G口，新增设备仍须重算端口/带宽与PoE。静音由用户另行考虑，不作为连接拓扑定稿的前置条件。本项目用户所说的 **AC 是主路由器/网关**，承担 WAN、NAT、防火墙、DHCP/VLAN；当前暂定 Fusion 把主路由与 Omada 控制器集成于同一物理设备，控制器应用负责管理，不另占端口。
- 小米/米家、华为设备不列入采购、备用或替代型号。旧文档/示例中的名称仅作历史追溯，不代表当前推荐，也不授权移除任何既有设备或服务。
- 所有本地模型先在目标 Mac Studio 上做内存、存储、量化格式、温度、并发和许可证验证；下载仓库的分支或权重变化不能直接当作稳定版本。

### 2.3 Thread 与各空间智能设备候选

下表是补充的 **Matter over Thread 设备类别候选**，不是已经选定、购买或验证的具体型号。保留现有 Aqara/Zigbee 方向，不强制把 Zigbee 设备替换为 Thread，也不把同一功能的多个候选重复计入采购数量。

| 空间 | Thread 设备类别候选 | 选型与安装约束 |
|------|--------------------|----------------|
| 主卧 | 智能灯/开关、窗帘、温湿度传感器 | 按照明回路、窗帘形式及实际可售型号确认 |
| 次卧 | 智能灯/开关、门窗、温湿度传感器 | 与其他区域一样预留智能功能，不因图示简化省略 |
| 工作室/电竞房 | 智能灯/开关、人体感应、温湿度传感器 | 人体运动/存在检测能力需分清，不仅按协议选型 |
| 大厅/入户 | 智能照明、入户门磁、人体感应 | 网关放大厅不代表只能管理大厅设备 |
| Bathroom A（中部卫生间，门朝主卧） | 水浸、温湿度、人体感应 | 核实防潮、防水、供电和安装区域；灯光/排风联动按实际回路设计 |
| Bathroom B（工作室右侧公共卫生间，门朝上） | 水浸、温湿度、人体感应 | 同上，点位和数量待现场确认 |

- Thread 设备连接 Thread Mesh，**不是直接连接 Wi‑Fi AP**。HomePod mini 等边界路由器在 Thread 与家庭 IP 网络之间转发；HomeView官方已列Thread能力，实机配网/同一网络凭据和恢复仍须验证。
- 目标为统一、可互通的 Thread 网络凭据；多个边界路由器是否加入同一网络须在配网和恢复测试中验证，不能仅凭数量推断统一 Mesh。
- 电池传感器通常不转发流量；需要时补充经过确认具备 Thread 路由能力的常电节点，不能把所有插电设备默认视为路由节点。
- Matter 是互通标准，不是单独的无线协议；Thread 支持也不自动等于 Matter 或 HA/Apple Home 双平台已验收。逐型号测试配对、共享/多管理员能力、离线控制与恢复。
- Zigbee 设备仍连接兼容 Aqara 网关；Wi‑Fi 设备连接所在区域 AP；PoE 摄像头连接就近房间交换机的匹配 PoE 端口。摄像头位置单独确认，不默认卧室或每房间安装。

完整接入关系、四区域设备分支及两个卫生间见 [智能家居与 Thread 拓扑图](smart-home-topology.md)。

### 6.2 AP 硬性规格（采购验收）

用户已确认四个主要区域各一条回中央柜的 Cat6A；主卧/次卧直接接 Wall AP，并利用其下联口接电脑/有线终端，不设设备箱或交换机。电竞房/大厅保留一箱一交换机及本地分支。每一个 AP 必须满足以下条件：

- 支持 Wi‑Fi 7；
- 有线回程/PoE 上联端口标称速率至少 2.5GbE；
- 支持与实际供电交换机/注入器匹配的 PoE 标准，最大功耗可用于预算；
- **主卧、次卧、工作室必须为面板 AP，各 1 台；大厅必须为吊顶（吸顶）AP，1 台**。AP 位于设备箱外；面板底盒/安装板的尺寸、孔距、深度及吊顶固定结构须与最终型号和现场条件匹配；
- 北美销售版本、固件和管理方式在下单前完成官方规格复核。

单口吸顶 AP 仅用于大厅候选，不能替代三间房间的面板 AP。三台EAP775-Wall均有1×2.5G+3×1G数据下联，不是只有卧室型号可用。主卧/次卧下联接电脑/终端；工作室Apple TV/投影可按点位使用1G下联，Mac/NAS/PC/J3455仍直连ES210。所有AP下联和Wi-Fi共享AP的2.5G上联，AP故障会影响其下联设备。四条主干不变，不增卧室电脑独立中央回线或Mac回线。

当前网络品牌统一按 TP-Link Omada 调研。用户于 **2026-10-13 暂选 EAP775-Wall ×3**，用于主卧、次卧、工作室；美国官网当日核验为 **BE11000、2.4/5/6GHz 三频 Wi‑Fi 7，上联 1×2.5G、下联 1×2.5G + 3×1G**。v1.2主卧/次卧电脑直接接AP下联；三个千兆下联口不能当作≥2.5G电脑口，四个下联与Wi-Fi设备共享AP的2.5G上联。工作室Mac仍接交换机10G，不因AP选型降速。大厅保留EAP772 ×1，本次全屋2.5G基线不需要EAP773；它也不用于工作室面板替代。三频销售规格解决原EAP725-Wall的频段规格缺口，**不等于已验证在中国大陆可合法启用6GHz**；地区功能、认证、供货及保修仍须采购前核实。

EAP775-Wall 官方尺寸为 **172.9×91.2×41.3mm**，随箱含墙面安装套件及可涂装盖板；底盒孔距、深度、线缆弯曲和实际附件仍需与现场/发货版本核对，不重复购买已含安装件。工作温度为 **0–40℃**，不得藏入设备箱。官方输入为 **802.3at/bt**，最高功耗 **45W（含 25W PoE Out）**；这不是裸 AP 功耗，也不能用 45−25 推定裸机保证为 20W。官网概览称 PoE Out 需要 802.3bt，规格表又写 802.3at，存在内在不一致；**本方案不使用 AP PoE Out，摄像头仍直接接就近房间 PoE 交换机**。后续若需转供，先取得对应硬件/固件的官方明确条件并重算预算。官方证据与购买入口见 [TP-Link 网络产品调研](tplink-network-research.md)。

### 6.3 交换机与 PoE 预算

- 中央与房间交换机分别核算上联、AP、电脑、服务器、控制器与备用端口；不要把全部多千兆端口都算成 PoE 必需口。
- 每台PoE交换机单独核算 `实际由该交换机供电的设备最大功耗之和 × 1.3`，同时核对单口功率。**三台EAP775-Wall按45W（含25W PoE Out）记录规格上限，不套用EAP772的25.4W，也不视为不转供时已测功耗；本方案不启用AP下游PoE，但使用卧室AP的数据下联口。** 无转供功耗未核清前可按45W保守预留并注明假设。主卧/次卧由中央两口直接供电，按这一保守上限中央仅两AP即需 `2×45×1.3=117W` 总预算（另加实际PoE负载），且每口需匹配bt能力；若采用at，先取得不转供模式与功耗的版本证据再重算。电竞房ES210XPP-M2直接给本房AP供电，200W全机预算仍核实际硬件/单口功率；大厅EAP772由大厅交换机供电。当前不追加AP注入器；普通本地交换机不透传中央PoE。

**三交换机 PoE 核算（2026-10-15；按目前 AP 上限 ×1.3，不是实测）：**

| 位置 | PoE 端口 / 单口 / 总预算 | 当前已知规划负载 | 余量与端口限制 |
|---|---|---:|---|
| 中央推荐 ES210XPP-M2，待确认 | 8×2.5G PoE++ / 90W / 200W | 主卧、次卧 EAP775-Wall：`2×45×1.3=117W` | 功率余约83W；5/8数据口已规划，另3口余量。中央若改型须重核至少两口bt及总预算。 |
| 电竞房 ES210XPP-M2，已选 | 8×2.5G PoE++ / 90W / 200W | 工作室 EAP775-Wall：`45×1.3=58.5W` | 功率余约141.5W；完整直连表占满交换机，但AP另有4个数据下联。低带宽终端可改接AP；不通过AP给摄像头/协调器供电。 |
| 大厅 ES206XPP-M2，已选 | 5×2.5G，其中4×PoE++ / 90W / 120W | EAP772：`25.4×1.3≈33W` | 功率余约87W；上联、AP、电视、`HALL-IOT-GW`后剩1个数据口。网关/摄像头型号未定，未计负载；到货后复核其逐口和总预算。 |

中央当前的 `83W` 余量不等于已批准的摄像头数量。智能灯、开关、电池传感器通常不走 PoE；摄像头、门铃、部分网关才会消耗 PoE。最终按设备最大功耗 ×1.3 重新加入预算。例如规划功耗 12W 的 PoE 设备 4 台约需 62.4W，5 台约需 78W，后者已经基本吃完中央余量，且还没有计入峰值/其他 PoE 设备。

- 中央与房间箱的尺寸、散热、插头间距、UPS 和线缆弯曲半径须现场测量；按当地市电及适配器铭牌核对供电。中央 UPS 不会自动覆盖本地市电供电的房间交换机/注入器，需逐位置评估备用电源。
