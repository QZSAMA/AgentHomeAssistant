## 4. 网络架构

### 4.1 已定物理拓扑：3A三频（2026-10-20暂定定稿）

J3455/HA在工作室接入，现1G/计划2.5G，沿用一个物理口；Fusion内置Omada控制器不另占交换机口。光猫保留运营商PON认证角色，Fusion承担路由；宽带计划1000/30Mbps不是已测速结果。

### 4.2 设计约束与布线要求

- 四条主干统一2.5G；仅工作室Mac原生10G RJ45、未来NAS 10G SFP+是本地10G。所有关键终端接工作室交换机，影音终端可改接AP的1G数据口。
- 主卧及电竞房面板AP共两台，大厅吊顶一台；次卧只做可维护RJ45墙口，预留将来AP位。大厅/电竞房的横梁、半墙及玻璃和卧室承重墙按实测调整无线覆盖。
- 两房间设备箱在电竞房/大厅；弱电箱在入户门左侧，中央设备位规划在该箱或附近通风核心柜，服务器和无线设备放箱外通风处。箱体、线长、端接、插座及附件须结合已归档原图现场复尺。
- 每台交换机按实际PoE协商和最终负载核单口/总预算，不使用AP下游PoE转供。次卧墙口默认关闭PoE。
- HA为J3455独立HAOS VM，尚未部署；Omada为Fusion内置控制器。NAS和UPS入住后再选，装修保留供电、空间及可维护管路。
- 6GHz硬件按用户偏好保留，实际启用条件沿用专项研究；普通智能家居2.4G SSID继续保留。

### 4.3 当前设备布局与采购

Fusion普通版×1、ES206XPP-M2×2（中央/大厅）、ES210XPP-M2×1（电竞房）、EAP775-Wall×2、EAP772×1共七台。三频为当前暂定定稿，双频EAP725-Wall×2/EAP723×1为相同3A的保留备选。[BOM](purchase-bom.md)与[采购数据](../config/network-procurement.json)维护统一型号、数量、单价和链接。

### 4.4 逻辑网络与 Apple Home/HA

第一阶段把 HomePod、Apple Home/Matter、Aqara 网关、Home Assistant 和主要智能设备放在同一个可信网络，先完成配网和端到端控制。第二阶段再考虑管理、主网、IoT、访客 VLAN；一旦分 VLAN，必须配置并验收双向 mDNS/Bonjour、IGMP snooping、控制器到 HA/设备的 ACL 和 HomePod/Matter 配网流程。智能家居 2.4GHz 设备需保留兼容 SSID，不能只启用 6GHz 或 WPA3-only。

Home Assistant 是设备编排和自动化核心，Apple Home 是家庭交互与生态入口。优先使用 HA 的 HomeKit Bridge 把已验证设备暴露到 Apple Home，并根据 Aqara/空调型号选择 Matter、HomeKit、Zigbee 或厂商集成；不能仅凭品牌名称保证兼容。

HA、Apple Home 控制器和 Thread 边界路由器角色不同，都不能泛化为必须串联的数据转发路径。Matter 多管理员与 HomeKit Bridge 按设备支持情况选择；Apple HomeView不替代HA、Aqara Zigbee网关或Mac模型服务，官方Siri AI不等于本地MLX模型的自由对话接入。
