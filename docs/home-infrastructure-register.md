## 4. 网络架构

### 4.0 同一LAN按设备分流（2026-11-05，方案已批准、未部署）

**当前批准范围：** 用户已批准所有设备保持同一家庭LAN/网段，不划分VLAN、不采用PPSK分网或家庭设备隔离。Fusion保留主网关、唯一DHCP与独立普通DNS。2.4GHz使用同一个SSID，智能家居自动走Fusion，指定手机/平板在该无线配置中手动指定固定地址、OpenWrt网关和规则DNS；日常5GHz及可用6GHz使用另一个SSID，仍桥接同一LAN、自动走Fusion，终端按需启用自己的客户端工具。逐设备DHCP网关覆盖没有确证，本方案不依赖该功能。见[批准版设计](superpowers/specs/2026-11-05-home-device-rule-routing-design.md)、[现行实施计划](superpowers/plans/2026-11-05-home-device-rule-routing.md)和[现行验收与应急单](validation/home-device-rule-routing.md)。

J3455仍在现有Proxmox新增独立OpenWrt完整VM，关闭家庭LAN的DHCP/RA；OpenClash/Mihomo作为实施前复核兼容性的候选。v1.6将宿主位置与接入口改为客厅箱外通风位、ES206的2.5G铜口，现网卡先协商1G；不重装宿主，不把搬迁、网卡升级和VM部署混为已完成。HAOS方向不变，宿主及其UPS负载一并纳入客厅；不增加独立主网关或备用VM。

**故障与验收边界：** J3455故障不改变其他设备普通联网与解析的路径；主动使用OpenWrt的终端可能失去外网，需手动切日常SSID或恢复自动IPv4/DNS，不承诺自动无感切换。宿主上的NAS/未来HA服务仍随宿主停机暂停。手动IPv4网关不代表IPv6规则已覆盖，不全局关闭本地IPv6/Thread；所有实机检查均为 `not_run`。

**实施边界：** 本次仅执行指定终端手动选用OpenWrt，不做全屋网关/DHCP迁移、定向DNS或合成地址段静态路由，也不更换主网关。[官方功能核验](fusion-domain-routing-capability-research.md)、[社区故障与兼容证据](home-routing-community-and-reliability.md)及[同SSID按设备调研](fusion-third-party-and-device-routing.md)保留原始来源，部署以当前设计、计划和验收单为准。

### 4.4 逻辑网络与 Apple Home/HA

按2026-11-05批准方案，所有有线/无线设备保持同一家庭LAN，不安排后续VLAN隔离阶段；Fusion为唯一DHCP与普通DNS，指定终端按4.0节手动选用OpenWrt。智能家居 2.4GHz 设备需保留兼容 SSID，不能只启用 6GHz 或 WPA3-only。

Home Assistant 是设备编排和自动化核心，Apple Home 是家庭交互与生态入口。优先使用 HA 的 HomeKit Bridge 把已验证设备暴露到 Apple Home，并根据 Aqara/空调型号选择 Matter、HomeKit、Zigbee 或厂商集成；不能仅凭品牌名称保证兼容。

HA、Apple Home 控制器和 Thread 边界路由器角色不同，都不能泛化为必须串联的数据转发路径。Matter 多管理员与 HomeKit Bridge 按设备支持情况选择；Apple HomeView不替代HA、Aqara Zigbee网关或Mac模型服务，官方Siri AI不等于本地MLX模型的自由对话接入。

## 5. Mac Studio 与模型部署计划

### 5.1 硬件约束

用户已明确采购目标为 **Mac Studio M5 Ultra，512GB 统一内存 + 4TB 内置 SSD**：512GB 是统一内存，不是硬盘容量；4TB 是内置 SSD 容量，不再保留“至少2TB/4TB优先”的待选建议。[Apple美国配置页](https://www.apple.com/shop/buy-mac/mac-studio)2026-10-15明确512GB选项10月下旬提供；[规格页](https://www.apple.com/mac-studio/specs/)列512GB对应M5 Ultra 36核CPU/80核GPU。目标512GB/4TB整机精确价格待开放后核验，$5,499是M5 Ultra起价而非该配置报价；仍未购买。HA主实例在J3455，Mac只承担模型/剪辑/开发与受控家庭服务。

模型权重按既有调研页面容量粗算约397GB，不等于实际运行内存占用或项目总磁盘需求。4TB SSD 还需为系统、运行时、缓存、视频素材/中间文件和开发数据预留空间；内存并发预算与存储/备份预算分别核算。外接存储、NAS 与备份容量仍另行评估，不因内置4TB而视为已购买或已落实备份。

用户确认 Mac Studio 使用 10GbE 网口，接工作室 10G 交换机。原生运行 MLX/MLX‑VLM/llama.cpp 等 Apple Silicon 服务；HA 已确定放在现有 J3455 的独立 HAOS VM，Omada改为暂定Fusion内置控制器；HA与Fusion均未部署。不能假设 Linux 容器直接获得 Metal/MLX GPU。所有服务先限制为局域网受控 API，工具调用采用白名单并记录审计日志。

J3455已知为16GB内存、10TB存储记录、现1GbE、Proxmox，用户确认西数金盘WD Gold、未做RAID；具体盘型/盘数、10TB原始或可用容量、健康及备份待核，无RAID不等于只有一盘。既有黑群晖VM和代理/转发容器保留，HAOS与OpenWrt仍在同一宿主部署方向，不能重装覆盖现有服务。v1.6规划将J3455移至客厅箱外通风位接ES206，以影视为主，网卡升级2.5G未购/未实施；宿主和服务的UPS、恢复测试改按客厅负载。Mac与未来10G NAS继续电竞房，不把J3455登记为10G NAS。

### 5.3 语音和 Apple Home 链路

用户已确认**Siri/Apple Home基础控制与本地模型自由对话都要做，但具体方案尚未决定**。HomePod/Siri不会自动把本地模型当后端；HA Assist + 本地识别/合成 + planner只是待验证实现方向。收音/唤醒终端、控制权限、播报与多房间体验需另做PoC，AirPlay音频输出不等于开放HomePod麦克风输入，不提前锁定或加购语音终端。Omni音频能力仍属实验，不作为家庭基础控制的前置依赖。
