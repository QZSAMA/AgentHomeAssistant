# 全屋智能增补查漏清单

日期：2026-11-18。范围：保持19,324元绿米签字清单不变，通过Aqara折扣新品渠道评估额外配件；先形成完整建议，再按报价决定预算。本文未下单、未改现有设备、未实施自动化。

“未列入”只表示采购资料里没有，不能证明装修方没有提供或用户没有另购。建议数量是询价/核对口径，不是现场下料或最终采购数量。本文是对《绿米之外的配件增补建议》的全屋查漏补充；同名设备是同一批数量，不与旧表相加。

**本轮已按用户决定收敛**：次卧照明暂不加；窗户只检测；水吧与餐边柜各用1只智能插座控制独立灯具；空调/新风/地暖/热水器统一欧瑞博；两卫为暖风/换气/干燥一体机，保留FP310；入户和沙发用FP400，不增场景按钮；漏水、柜温及烟雾/燃气/门锁门铃加入询价。具体数量及浴室接入路线见[当前增补建议](aqara-supplement-plan-20261118.md)。

| 类别 | 完整建议口径 | 优先级与适用条件 |
|---|---|---|

| 起夜照明 | Aqara感应小夜灯建议2只；需要联网时另选低位灯具方案 | 独立小夜灯自带人体/光敏、不接HA；位置合适时复用主卧M1S夜灯可减1只。独立灯与联网灯带互为用途选择，不双份默认采购 |
| 外窗/阳台门磁 | 新增候选2–4只 | 只检测开闭和提醒；不买开窗/关窗执行器，不与玄关原有门磁重复 |
| 水浸 | 先询3只重点位；两卫柜内另报0–2只 | 厨房水槽/净水区、洗衣区、分离的洗碗机漏水点各1；共用汇水区域时可减为2只。用户确认需要 |
| 湿度/排风联动 | 两卫FP310复用；控制配件待一体机接口确定 | 优先厂家支持且可接入的智能模块；其次核真正红外；有明确外部控制输入才配匹配模块。专用总线/RF/蓝牙不能默认用通用继电器替代，不先锁0–2只继电器采购 |
| 空调/新风/地暖/热水器 | 统一欧瑞博，具体SKU待定 | 品牌方向已确定；供应商需分别交付四类设备的控制接口、状态反馈及HA/Apple Home接入说明。两卫一体机是另行选型，不与全屋新风混为同一设备 |
| 水吧/餐边柜局部照明 | 独立照明＋智能插座2只 | 各1只通断控制，保留灯具原电源/驱动；先确认上电可亮。仅需开关时不增加灯带驱动或调光模块 |
| 无线场景按钮 | 入户/沙发新增0只 | 用户改用FP400；电竞桌/床头原建议旋钮2只保留 |
| 房间温湿度 | 原主卧/电竞房合计0–2只仍保留 | 先确认已有设备是否提供足够稳定的读数和HA实体；仅为看数据不机械地每房买一只 |
| 设备柜温度 | Aqara温湿度传感器先1只，T1作为询价候选 | 测柜内空气，闭门验证信号；主机内部温度另用软件读。其他位置设备柜若需要独立温度，再增测点 |
| 智能插座 | 共5个候选位：家电计量3＋独立照明2 | 家电逐一匹配负载规格；灯光两只主要做通断，与上方水吧/餐边柜为同一批，不重复累计 |
| 烟雾报警 | 先询2只 | 用户同意加入；最终点位和覆盖按实际布局、说明书复核，要求独立本地报警 |
| 燃气报警 | 先询1只 | 用户同意加入；气种和安装位置待核。天然气型号不默认适配液化气，不包含燃气阀/管路改造 |
| 门锁/门铃 | 门锁1套＋可视门铃1套候选，分别询价 | 门体/锁体与所需Apple Home/HA能力决定型号。若锁的门铃/视频功能已满足用途，可取消独立门铃；原客餐厅E1不因此移除 |
| 自动关水 | 后置候选1套，先核管路/阀门适配和维护 | 漏水传感器只负责发现与通知。若需要自动止水，再评估匹配执行器/阀门及人工操作方式，由合适人员实施；不与报警器捆绑为首期必购 |
| CO₂/空气质量 | 后置0–1个候选测点 | 仅在关窗久坐/新风控制有实际需求时评估；要求需要的真实测量指标和可用数据，不能把普通温湿度或估算eCO₂等同真实CO₂。型号与是否由Aqara渠道供货均未核，不列必购 |

以上传感器数量不代表一只可隔墙覆盖多个房间。厨房/次卧是否增加存在感应，应在确有自动化需求和现场视场验证后决定；不默认所有房间都上昂贵多区域雷达。

## 4. 还缺的是场景配置，而非新设备

| 场景 | 需要的闭环 | 可复用部分及边界 |
|---|---|---|
| 入户/离家 | FP400入户区检测参与欢迎/通行场景；离家仍需可靠条件 | 区域暂时无人或门刚关上不等于全家离开。冰箱、网络、HA、NAS及仍在运行的洗烘/洗碗设备不加入普通“全部断电”列表；不新增入户按钮 |
| 沙发/观影 | FP400沙发区检测参与局部照明；观影状态与设备工作状态配合 | 坐在沙发不默认等于要开电视。观影中不因动作重新开主灯；投影使用正常关机方式；不新增沙发按钮 |
| 起夜 | 夜间离床/通行 → 低位柔光 → 延时或离开后关闭 | 优先检查现有感应覆盖；床上持续存在不是起夜触发条件 |
| 洗澡排湿 | FP310湿度持续升高 → 给一体机换气命令 → 回落后延时正常停止 | 湿度检测已有官方收录依据，上报/HA实体待验；一体机接口待型号确定，不切总电源代替停止，不用存在事件直接自动加热 |
| 家电完成提醒 | 功率确认运行 → 持续结束特征 → 一次提醒 | 各机器独立校准；掉线/数据陈旧显示未知，不当成已完成 |
| 漏水通知 | 现场检测 → 本地/手机告警 → 人工处理，后续可选止水 | 两个独立位置应分别能定位来源；关键本地报警不依赖HA主机或云端正常运行 |
| 窗户状态 | 门窗开闭 → 显示和未关提醒 | 本期无窗户执行器；欧瑞博空调跨生态联动待接口核验，不默认实施开窗自动关空调 |
| 维护 | 低电量、离线、HA服务异常与自动化失败可见 | 优先现有软件能力，不另买网关补“监测”。本地物理开关及正常手动使用方式保留 |

## 5. 装修阶段容易漏掉的配套

- 次卧、厨房操作灯、夜灯、追加屏幕等对应的零线、底盒、灯路、电源与检修位置；需要调整施工的由装修方按现场落实，不改变原签字单的数量。
- 磁吸轨道/电源/连接件完整匹配；新增灯带单独核控制器、电源、长度和补电。可分区控制要有对应控制通道。
- 若电竞房/次卧希望以后电动窗帘，确认实际窗户与遮光形式后预留电源和轨道安装空间，不立即锁轨道米数。
- 智能插座按每台家电负载和10A/16A插头选型；嵌入式家电后方留得下且可维护。继电器/电源不能藏到无法检修的位置。
- 新增传感器的支架、安装面、电池型号和拆换空间；不为电池设备无依据增设网线或PoE。
- 原有网络、服务器、UPS和跨房HDMI规划已经有独立文档；UPS原定入住后按负载评估，仍维持此节奏，不在本次重复打包购买。

## 6. 建议决策顺序

1. 按本轮范围询价：家电计量3点、水吧/餐边柜照明2点、重点漏水3点、夜灯2只、窗磁2–4只、柜温1只、烟感2只、燃气1只、门锁/门铃各1套候选；这些都是与主表去重后的口径。
2. 保留既有体验增补：电竞房灯带、两只旋钮、主卧屏、磁吸灯和公共区FP400；不加次卧照明和入户/沙发按钮。
3. 先定接口后买配件：欧瑞博四类系统、两卫暖风/换气/干燥一体机、门锁门铃的具体SKU及实际接入方式；后置自动关水和空气质量等未确认项目。

门锁/门铃、空调、燃气和嵌入式家电的具体型号未确认前，保持“核对/条件项”，不猜型号或硬凑采购数量。Aqara渠道新品也要逐型号核所需功能能否经最终选定路径进入Apple Home/HA；不承诺全部私有功能都能桥接。
