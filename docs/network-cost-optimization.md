## 端口与供电

中央ES206的五铜口分配给Fusion和四主干，全部预分配；次卧空置时实用四口，第五口留给次卧。中央只给主卧AP供电；电竞房和大厅各给本地AP一个PoE口。ES206有4个PoE++口/120W、ES210有8个PoE++口/200W，均为单口最高90W。

775输入支持at/bt，45W标称上限含25W下游转供；本案关闭AP PoE Out，不由差值推裸机功耗。772为at输入、最大25.4W。工作簿按at端口30W分配作初步规划，需按实机协商、控制器预留和冷启动复核；若协商bt，按实际预留重算，交换机单口均具有bt能力。新增摄像头/网关另计其端口和负载。

## 2. 两种接法

### 3A：小型中央 PoE 交换机（当前主案）

```text
光纤 → 光猫/ONT → Fusion 2.5G 普通版 → 中央 ES206XPP-M2
                                              ├─ PoE → 主卧 EAP775-Wall
                                              ├─ 预留 → 次卧 Cat6A / RJ45 墙口 → 可选已有 TL-7DR3630（市电）
                                              ├─ 2.5G → 工作室 ES210XPP-M2 → 本地 AP / Mac / NAS / 终端
                                              └─ 2.5G → 大厅 ES206XPP-M2 → 吊顶 AP / 电视 / 网关
```

中央 ES206XPP-M2 的 5 个 2.5G 铜口规划给 Fusion、主卧 AP、次卧预留主干、工作室和大厅，**全部预分配**；次卧未启用时实际空闲一口，10G SFP+ 未占用。中央目前仅主卧 AP 使用一个 PoE++ 口；次卧墙口默认关闭 PoE，接 TL-7DR3630 时也不启用 PoE。

### 3B：Fusion 2.5G PoE 一体机（整合备选）

```text
光纤 → 光猫/ONT → Fusion 2.5G PoE
                        ├─ PoE → 主卧 EAP775-Wall
                        ├─ 预留 → 次卧 Cat6A / RJ45 墙口 → 可选已有 TL-7DR3630（市电）
                        ├─ 2.5G → 工作室 ES210XPP-M2
                        └─ 2.5G → 大厅 ES206XPP-M2
```

Fusion 2.5G PoE 是另一款硬件，不是普通 Fusion 开启一个设置。它有 1 个 2.5G WAN 和 8 个 2.5G LAN/WAN（均可 PoE+）、110W PoE 预算、有风扇；本方案四条主干规划占 4 个口，次卧未启用时实际占 3 个 LAN 口。官方商城当前为预售，Amazon 显示少量库存；供货、风扇噪声、电源铭牌和跨房并发仍需验收。

## 4. PoE 边界

- EAP775-Wall 支持 802.3at/bt 输入；45W 标称上限包含最多 25W 下游 PoE Out。本方案禁用下游转供，不用 `45−25` 推断 AP 裸机功耗。EAP772 官网最大 25.4W，支持 802.3at；下单按实际版本复核。
- 当前按 802.3at 的 PSE 分配上限 30W/口规划：中央主卧 1 台 AP 为 30W，工作室和大厅各 30W。次卧墙口无 PoE 负载；端口上限不再额外乘 1.3，因为这会重复放大供电分配上限。
- ES206XPP-M2 为 90W/口、120W 总预算；ES210XPP-M2 为 90W/口、200W 总预算；Fusion PoE 为 8 个 PoE+ 口、110W 总预算。实际协商、控制器预留、冷启动和满载必须到货验证。
- 控制器模式下需验证手动 PoE 重启；不把独立模式的 PoE Auto Recovery 自动等同于控制器模式。

## 5. 下单与验收门槛

1. 卖家书面确认 EAP775-Wall 与 EAP772 的地区 SKU、硬件版、包装/下联口、供电规格和退换条款；EAP775-Wall 的 1×2.5G + 3×1G 下联要与安装实物一致。
2. Fusion 内置控制器能接管实际硬件版本的交换机和 AP；验证 adoption、VLAN、SSID、配置备份与恢复。
3. 验证四条主干 Cat6A 永久链路，已启用的三条链路 2.5G 协商、三台 AP 的 PoE 冷启动和满载、Mac 本地 10G，以及已购面板 AP 的 1×2.5G + 3×1G 下联。次卧空置线的 2.5G 协商待接设备时再测；不以中国大陆 6GHz 连接成功为交付前提。
4. 采用 3B 时，再做两组跨房 `iperf3` 并发、VLAN/SSID 转发、PoE 重启和整机断电恢复；不能仅由端口数量推断总交换吞吐。
5. 美国 SKU 能使用 100–240V 的设备仍需核对随箱插头、交流输入铭牌、中国使用合规及跨境保修。
