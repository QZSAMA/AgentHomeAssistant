# 武汉印 3D 户型小样 Implementation Plan

> For agentic workers: execute the tasks below in this session with separate owners for CAD data, simulation state and NeonPlan conversion. The user approved proceeding with the proposed living/dining/studio sample on 2026-11-21.

**Goal:** Produce a locally reviewable CAD-based 3D home with clickable simulated lights, plus an upstream-validated NeonPlan import path.

**Architecture:** Canonical metre-based house geometry is derived from the already converted user DWG. A local Three.js viewer consumes this geometry and a pure simulation store; a separate exporter converts the same geometry to NeonPlan. No credentials, real-device calls or remote uploads are required.

**Tech Stack:** Local Three.js 0.180.0 / OrbitControls, HTML/CSS/ES modules, Python/ezdxf/Shapely, node:test, Python Playwright, loopback HTTP server.
